# Directorio `src/`

## Propósito Arquitectónico

Lógica de canalizaciones y módulos de Python.

## Contexto, Origen y Justificación Técnica

Contiene el código fuente principal y los scripts reutilizables. La extracción de la lógica de procesamiento desde entornos interactivos (como *Jupyter Notebooks*) hacia módulos de Python estructurados demuestra madurez en la ingeniería de software, permitiendo que el código sea testable y reutilizable.
